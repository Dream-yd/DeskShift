# 使用与恢复

幕间 DeskShift V1.0，原名会议桌面。首次使用前，请备份桌面重要文件，保存图标布局，并记录原桌面文件夹位置。默认数据目录和可执行文件名与旧版一致；升级前退出旧版托盘进程。

## 切换

1. 在设置中选择一个独立的备用桌面文件夹。设置保存后，在切换页核对目标路径。
2. 公共桌面快捷方式的处理可能需要管理员授权。使用“提前授权”后，切换可复用本次运行期间的授权；授权状态变化时按界面提示处理。
3. 在切换页切换到备用桌面。在同一页返回原桌面；快捷键、桌面中键和托盘入口也可配置为切换。
4. 返回后核对图标和文件。备用桌面中的文件仍在备用文件夹。

默认数据目录为 `%LOCALAPPDATA%\MeetingDesktop`。设置页提供恢复备份导出。自动快照可按需设置保留期限；活动会话依赖的快照不会被软件删除。

## 恢复不完整

打开“恢复与修复”查看结果与下一步；“诊断”可导出经过路径脱敏的报告供检查。未匹配、位置偏差、无法确认身份和公共快捷方式冲突应分别核对。没有确认含义前，不要删除、覆盖或手工编辑恢复记录。

如果提示公共桌面快捷方式的处理结果无法确认，程序会保留记录并停止猜测。请核对公共桌面与其备份文件夹，再决定如何处理。不要使用不理解新记录格式的旧版软件继续操作。

## 更新与卸载

退出托盘中的旧实例后再启动新版；可在新版设置页显式更新旧版开机自启项。卸载前先回到原桌面、核对文件和图标，并自行备份需要保留的布局与配置；删除程序目录不会自动清除用户数据。
