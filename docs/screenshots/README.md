# 界面截图 / UI screenshots

These PNGs were captured on 2026-10-28 from the released DeskShift V1.0 WPF controls in an isolated rendering harness. They are UI captures, not mockups or images generated by an image model.

The harness uses example directories under `E:\DeskShift-Demo`, three demonstration layout snapshots, and the application's own Chinese/English resources and dark/light palettes. Native desktop switching, startup registration and authorization actions are not executed. Personal desktop preview capture is disabled, so the switch page intentionally shows no preview. No personal desktop image or user file list is included.

这些图片来自 V1.0 实际 WPF 界面控件的隔离渲染截图，不是概念设计图。目录、布局和状态使用演示数据；未执行桌面切换、系统自启注册或提权操作。为保护隐私，未加载个人桌面预览。截图仅展示界面，不作为功能或性能验收依据。
