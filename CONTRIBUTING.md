# Contributing

For build and test instructions, see [development notes](docs/DEVELOPMENT.md). Keep changes to desktop paths, icon positions, public shortcuts, wallpaper and recovery records separately testable with temporary files or fakes. Real desktop acceptance belongs in a disposable Windows environment with a recovery plan.

Before sharing diagnostics, remove personal paths, file names, screenshots, tokens and other private information. Please describe the Windows version, application version, switching mode, expected behavior and reproducible steps. Do not upload recovery records or desktop screenshots containing personal data to a public issue.
